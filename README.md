# 난세영웅전 (亂世英雄傳)

이 저장소에는 두 가지 버전이 있습니다.

- **[`action/`](action/) — 난세무쌍**: 메이플스토리 스타일의 횡스크롤 액션 RPG (직접 조작)
- **루트 — 난세영웅전**: 턴제 전투 RPG

## 난세무쌍 (횡스크롤 액션)

### 아이폰·아이패드에 앱으로 설치하기

1. Safari로 **https://soonyou3k.github.io/Mini/** 를 엽니다.
2. 아래쪽 **공유** 버튼 → **홈 화면에 추가**를 누릅니다.
3. 홈 화면의 **난세무쌍** 아이콘으로 실행하면 주소창 없이 전체 화면으로 열리고, 한 번 연 뒤에는 인터넷 없이도 플레이할 수 있습니다.

가로로 눕히면 화면이 가장 넓게 보입니다. 방향 패드는 손가락을 떼지 않고 미끄러뜨려도 방향이 바뀝니다.

`main` 또는 개발 브랜치에 푸시하면 `.github/workflows/pages.yml`이 자동으로 배포합니다. 설치한 앱은 다음 실행 때 새 버전을 받습니다.
(처음 한 번은 저장소 **Settings → Pages → Source**를 **GitHub Actions**로 설정해야 합니다.)

PC에서는 `action/index.html`을 브라우저로 열어도 됩니다.

- **직업**: 관우(검호·근접), 황충(신궁·원거리), 제갈량(책사·마법)
- **조작**: ←→ 이동, Space/Alt 점프(↓+점프로 발판 아래로), Z/Ctrl 공격, A·S·D 기술, ↑↓ 밧줄·포탈·대화, 1·2·3 물약. 휴대폰에서는 화면 버튼으로 조작합니다.
- **맵 7개**: 탁현 마을 → 탁현 들판 → 황건 산채 → 광종 제단(보스 장각) → 연합군 진영 → 사수관 성벽 → 호뢰관(보스 여포)
- **퀘스트 7개**, 몬스터 드롭(오수전·물약), 레벨업, 대장간 무기 강화, 미니맵, 자동 저장
- 그림 파일 없이 캔버스에 도형으로 모든 캐릭터와 배경을 그립니다.

| 파일 | 내용 |
| --- | --- |
| `action/js/data.js` | 직업, 기술, 몬스터, 맵, NPC, 퀘스트 |
| `action/js/game.js` | 물리, 전투, 몬스터·보스 AI, 저장 |
| `action/js/draw.js` | 캔버스 그리기 |
| `action/js/ui.js` | HUD, 대화창, 상점, 터치 조작 |
| `action/sw.js`, `action/manifest.webmanifest` | 홈 화면 앱 설치·오프라인 실행 |
| `scripts/build-pages.sh` | GitHub Pages용 사이트 빌드 (`/` 난세무쌍, `/classic/` 턴제) |

## 난세영웅전 (턴제)

삼국지를 배경으로 한 브라우저 턴제 RPG입니다. 빌드 과정 없이 `index.html`을 브라우저로 열면 바로 실행됩니다.

## 게임 소개

- **세력 선택**: 촉(유비·관우·장비), 위(조조·하후돈·허저), 오(손견·황개·손책). 3장 이후 제갈량 / 곽가 / 주유가 합류합니다.
- **다섯 장의 캠페인**: 황건적의 난 → 사수관 → 호뢰관 → 관도대전 → 적벽대전. 장마다 세 개의 전장, 마지막은 결전(보스)입니다.
- **턴제 전투**: 민첩 순서대로 행동하며 공격 · 책략 · 도구 · 방어 · 퇴각을 고릅니다. 화상, 기절, 공격/방어 강화 같은 상태 효과가 있고, 여포·조조·주유 같은 총대장은 한 합에 두 번 움직입니다.
- **진영**: 수련으로 경험치와 금을 모으고, 주막에서 쉬고, 상점에서 도구를 사고, 대장간에서 무기·갑옷을 단련합니다.
- 진행 상황은 브라우저 `localStorage`에 자동 저장됩니다.

## 파일 구조

| 파일 | 내용 |
| --- | --- |
| `index.html` | 진입점 |
| `style.css` | 화면 스타일 |
| `js/data.js` | 무장, 책략, 적, 도구, 장(章)과 대사 데이터 |
| `js/engine.js` | 전투·성장 규칙 (DOM 없음) |
| `js/ui.js` | 화면 그리기와 입력 처리 |

새 무장이나 전장을 추가하려면 대부분 `js/data.js`만 고치면 됩니다.
